# VeriTalent 🔍
AI-powered talent verification platform.

## Problem
Resumes are easy to exaggerate, and recruiters have no quick way to verify skill claims.

## Solution
VeriTalent creates an evidence-based **Digital Twin** of each candidate by analyzing:
- Resume
- GitHub activity
- Technical interviews
- Skill claims

Recruiters see what a candidate can actually do, not just what they say.
